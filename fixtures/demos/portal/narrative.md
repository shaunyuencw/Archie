## What runs where
- Employee workstation [employee] is a employee access in Client · user devices. Status: proposed; 1 declared instance. Form: physical.
- Service desk workstation [service-desk] is a service desk access in Client · user devices. Status: proposed; 1 declared instance. Form: physical.
- Portal web service [portal-web] is a web frontend in Z1 · application services. Status: proposed; 1 declared instance. Form: virtual. Runs on Application hosts.
- Request application [portal-app] is a request processing in Z1 · application services. Status: proposed; 2 declared instances. Redundancy: active active. Form: virtual. Runs on Application hosts.
- Application hosts [app-host] is a application compute host in Z1 · application services. Status: proposed; 2 declared instances. Redundancy: active active. Form: physical.
- Zone firewall [zone-firewall] is a zone enforcement in Z1 · application services. Status: proposed; 1 declared instance. Form: virtual. Runs on Application hosts.
- Request database [request-db] is a protected relational data and audit records in Z2 · protected data. Status: proposed; 2 declared instances. Redundancy: active passive. Form: physical.

## Connections
- Employee workstation → Portal web service [employee-web]: service requests, using HTTPS (port 443); Employee workstation starts the session. Data flow: bidirectional. Enforcement: not recorded.
- Service desk workstation → Portal web service [desk-web]: service desk actions, using HTTPS (port 443); Service desk workstation starts the session. Data flow: bidirectional. Enforcement: not recorded.
- Portal web service → Request application [web-app]: request processing, using HTTPS (port 443); Portal web service starts the session. Data flow: bidirectional. Enforcement: not recorded.
- Request application → Request database [app-database]: database access, using PostgreSQL (port 5432); Request application starts the session. Data flow: bidirectional. Enforcement: Zone firewall.

## Requirements and open decisions
- no internet: True.
- resilience required: True.
- availability strategy: undecided.
- equipment sizing: undecided.
- client direct database access: forbidden.
- What end-to-end availability strategy should be used for the portal? Not decided.
